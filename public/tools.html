Maintenance mode

While on, AirPSX starts nothing by itself: tasks, scheduled backups, queued installs and decrypt jobs wait. Manual actions still work.

Alerts & webhooks

Overheat alerts post a message (Discord/Slack compatible). Event webhooks post JSON for Home Assistant, n8n and similar.

Task triggers

Choose when each task runs. Time-based tasks use their interval from the Scheduler app; event tasks run when the event happens.

Save backups

Scheduled tar backups of save data to any mounted folder (USB drive, network share). Console only.

Install queue

Queue several packages and install them one after another. Add a URL, a .pkg file path, or a folder of .pkg files (USB drive, mounted share).

“submitted” means the console accepted the package; installation progress is shown by the console itself.

Resumable upload

Uploads in 4 MB chunks. A dropped connection or a page reload does not lose progress: pick the same file and destination again to continue. Files must be smaller than 2 GB.
